# Promptly v0.8.0

Promptly can now make artwork and live text share a composition, and lets you keep
the parts you like while rerolling the rest.

- Strokes can meet a field edge or disappear behind protected username/directory
  text. Separate fields, disconnected fragments, compact prompts, and sprawling
  networks all remain in the automatic sampling range.
- Compact surfaces have independently chosen round, flat, and angled ends,
  cutouts between fields, and compatible thin accents. Curved top/bottom block
  contours remain confined to older saved recipes.
- Shared motifs evolve through shortening, shifting, thinning, and fragmentation.
  They appear in freeform fragments, network annotations, and text treatments.
- `promptly explore` adds an interactive slot machine. Pin a whole shape, the text
  layout, colors, or an individual assembly fragment; focus a fragment, keep
  favorites, compare variations, and export your winner.
- `--favorites FILE` explicitly persists favorite recipes. `--out FILE` exports a
  prompt without overwriting existing files unless `--force` is supplied.
- Version-7 recipes store independent component and fragment seeds. Saved
  versions 1–6 retain their generators and appearance. Exported prompts remain
  standalone native zsh, without drawing loops, editing hooks, or subprocesses.

Upgrade: `brew update && brew upgrade promptly`

Roll: `promptly` · Browse: `promptly explore` · Save a winner:
`promptly explore --favorites favorites.json --out winner.zsh`

Bare `promptly` still prints sourceable shell code. The optional explorer uses
stdin/stderr for its interface; `promptly explore > winner.zsh` writes only an
explicitly exported winner to stdout. No shell startup files are modified.

Standalone downloads are available for macOS and Linux, ARM64 and x86-64.
`SHA256SUMS` contains archive checksums. No Node or Bun installation is required;
previews and exported prompts use zsh 5.8+. Optional Powerline end caps require
font or terminal glyph coverage.
