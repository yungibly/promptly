# Promptly v0.7.0

Run `promptly` for a fresh roll across the whole procedural range: refined compact
prompts, colored capsules, connected circuitry, and larger freeform compositions.
Complexity now samples 1–10 independently of the engine, row budget, visual weight,
and colors. Explicit flags and saved recipes remain reproducible.

- Live username and directory fields use native zsh expansion, with reserved space
  for readable text and command entry.
- Compact compositions start from text relationships. Shared surfaces, horizontal
  half-circle ends, brackets, thin rules, and bare text can combine without the
  bulky top/bottom contour treatments from the earlier experiment.
- Color relationships are generated continuously. `--color-seed` changes color
  independently; `--weight` controls visual mass separately from complexity.
- Galleries balance every procedural family and compare occupied geometry,
  spacing, and material rather than relying on different colors to imply variety.
- Older recipes retain their generators and appearance. Exported prompts remain
  standalone zsh: no Node/Bun process, network access, prompt-time subprocesses,
  shell drawing loops, or editing hooks.

Install: `brew install yungibly/tap/promptly`

Upgrade: `brew update && brew upgrade promptly`

Generate: `promptly` · Copy: `promptly | pbcopy` · Try in zsh: `source <(promptly)`

Preview: `promptly --preview` · Explore: `promptly gallery`

macOS and Linux downloads are available for ARM64 and x86-64. Extract an archive
and put `promptly` on your PATH. No Node or Bun installation is required.
`SHA256SUMS` contains archive checksums. Previews and exported prompts require zsh
5.8+; optional `--glyphs powerline` needs a font or terminal covering its end caps.
